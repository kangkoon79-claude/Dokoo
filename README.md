# 뻥이요

밤 시장 뻥튀기 기계로 타이밍을 맞추는 웹 게임입니다.

## 하는 법

1. 판마다 목표 시간(3.0~9.0초)이 랜덤으로 나옵니다.
2. 화면을 꾹 누르고 있으면(또는 스페이스바) 레버가 돌아갑니다. 누르는 순간 "시작!" 신호와 함께 시간이 흐르기 시작하고, 목표 시간은 사라집니다.
   레버는 맨 위에서 출발해 정확히 1초에 한 바퀴 돕니다. 돌아가는 동안 소리는 나지 않습니다.
3. 목표 시간이 됐다 싶을 때 손을 떼면 "뻥이요!" 하고 터집니다.
4. 목표에 가까울수록 뻥튀기 상태가 좋고 점수가 높습니다. 한 게임은 5판, 만점은 5000점입니다.

| 차이 | 결과 |
| --- | --- |
| ±0.05초 이내 | 황금 뻥튀기 (1000점) |
| ±0.15초 이내 | 완벽한 뻥튀기 |
| ±0.30초 이내 | 바삭 고소 |
| ±0.60초 이내 | 먹을 만함 |
| 0.6~1.5초 일찍 | 덜 튀겨짐 |
| 1.5초 넘게 일찍 | 생쌀 그대로 |
| 0.6~1.5초 늦게 | 살짝 탐 |
| 1.5~3초 늦게 | 새카맣게 탐 |
| 3초 넘게 늦게 | 숯덩이 |

## 실행

`index.html` 하나로 된 게임입니다. 브라우저로 파일을 열면 바로 플레이할 수 있습니다.
